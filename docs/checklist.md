# Чек-лист ручной проверки

Сайты часто меняют разметку, поэтому после обновления расширения или раз в пару недель стоит пройтись по списку. Проверка занимает минут 10. Если что-то сломалось, смотрите консоль страницы (сообщения `[media-saver]`) и консоль service worker в `chrome://extensions`.

Перед проверкой: `npm run pack`, затем ⟳ у обоих расширений в `chrome://extensions`. Файлы появляются в `Загрузки/<сайт>/<автор>/`.

## Instagram

- [ ] Лента: фото-пост — кнопка ⬇ в строке под постом, файл скачивается.
- [ ] Лента: карусель — ⬇ качает текущий слайд, «Все N» качает все.
- [ ] Лента: видео — скачивается видео со звуком, а не обложка.
- [ ] Пост `/p/…`: кнопки есть, «HD <ширина>» появляется у фото с оригиналом больше 1080 и качает его.
- [ ] Reels `/reels/…`: ⬇ в колонке справа.
- [ ] Профиль и Explore: кнопка поверх плитки качает весь пост, в том числе у первых плиток.
- [ ] Сторис: ⬇ в шапке, качается текущая сторис (фото и видео).
- [ ] Хайлайты: то же, что сторис.
- [ ] Правый клик → «Media Saver ▸ Скачать / Скачать весь пост / Скачать оригинал (HD)».

## X (Twitter)

- [ ] Твит с фото: ⬇ в строке действий, фото в оригинале (`name=orig`).
- [ ] Твит с видео и с GIF: скачивается mp4.
- [ ] Твит с несколькими фото: качаются все.
- [ ] Правый клик → «Media Saver ▸ Скачать».

## TikTok

- [ ] «Для вас»: ⬇ в колонке справа, видео скачивается.
- [ ] Фото-пост: качаются все фото.
- [ ] Плитки профиля: кнопка поверх превью.
- [ ] Настройка «Совместимое качество» даёт H.264.

## LinkedIn

- [ ] Пост с фото: ⬇ после «Отправить», папка — автор поста (не `unknown`).
- [ ] Пост с несколькими фото: качаются все.
- [ ] Пост с видео: скачивается mp4 со звуком, видео запускать не нужно.

## Media Saver for YouTube

- [ ] Ролик: «Видео» под роликом показывает проценты, файл появляется в `Загрузки/youtube/@канал/`.
- [ ] «Превью» качает картинку в максимальном размере.
- [ ] Shorts: «Видео» и «Превью» в колонке справа.
- [ ] Правый клик по плитке в ленте → «Скачать превью».
- [ ] Если «Видео» выдаёт ошибку про хелпер — запустить `native-host\install.ps1` ещё раз (см. README).

## Настройки

- [ ] Страница настроек: шаблон пути меняет имена файлов, предпросмотр обновляется.
- [ ] «Спрашивать, куда сохранить» открывает окно для одного файла, но не для «Все N».
